The background of this page is the engine. This is the code:

<canvas id="komorebi" style="position:fixed; inset:0; width:100%; height:100%; z-index:-1"></canvas>
<script src="/komorebi.player.min.js"></script>
<script>
  Komorebi.create(document.getElementById('komorebi'),
    { params: Komorebi.PRESETS['morning 2'] });
</script>

Download komorebi.player.min.js and serve it from your own site. Do not link to the copy here.

  • A page background

    Full width behind the content. Changes look on a timer, and stops in a hidden tab.

  • A panel

    The canvas in a box instead of the window. Buttons change the look.

  • ES modules

    Import the modules instead of the bundle, and change one parameter.

  • The editor

    Every parameter, with a tooltip for each. Use it to choose a look.
